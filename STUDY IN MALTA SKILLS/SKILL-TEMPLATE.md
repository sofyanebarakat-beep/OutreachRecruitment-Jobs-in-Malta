## URL ROUTING RULES — MANDATORY

These rules apply to every article generated by this skill. Follow them exactly.

### Rule 1 — Study in Malta articles → `/malta-study-guide/`

Any article about **studying in Malta** (visa, universities, costs, accommodation, scholarships, English courses, student life, post-study work, etc.) must use this URL pattern:

```
https://outreachrecruitment.net/malta-study-guide/[slug]
```

Examples:
- `https://outreachrecruitment.net/malta-study-guide/student-accommodation-in-malta`
- `https://outreachrecruitment.net/malta-study-guide/malta-student-visa-complete-guide`
- `https://outreachrecruitment.net/malta-study-guide/cost-of-living-in-malta-as-a-student`

**Canonical tag must be:**
```html
<link rel="canonical" href="https://outreachrecruitment.net/malta-study-guide/[slug]" />
```

**og:url must be:**
```html
<meta property="og:url" content="https://outreachrecruitment.net/malta-study-guide/[slug]" />
```

**File must be saved to:**
```
malta-study-guide/[slug].html
```
(relative to the project root — NOT inside `STUDY IN MALTA SKILLS/generated/`)

---

### Rule 2 — General blog articles → `/[slug]` (root level, no `/blog/` prefix)

Any article that is a general blog post (career advice, recruitment, team structure, etc.) must use the root-level URL pattern — **never `/blog/slug`**:

```
https://outreachrecruitment.net/[slug]
```

Examples:
- `https://outreachrecruitment.net/why-malta-is-becoming-europes-top-destination`
- `https://outreachrecruitment.net/how-decision-clarity-removes-friction`

**Canonical tag must be:**
```html

```

**File must be saved to:**

(project root — NOT inside `/blog/`)
